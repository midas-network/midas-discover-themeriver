# Data formats

This document describes the data the ThemeRiver app consumes, so the datasets
are interoperable and reusable independently of the visualization.

All data files live in `data/`. Two files describe each dataset, plus one
generated manifest that indexes them.

## File naming convention

```
<source>-ngram_<n>-counts.csv     # theme counts per year (drives the ribbons)
<source>-ngram_<n>-papers.json    # papers behind each theme/year (drives the lists)
```

- `<source>` — the extraction source id (e.g. `meshTerms`, `pubmedKeywords`,
  `paperAbstract`). Any id is allowed; it becomes a selectable control.
- `<n>` — the n-gram size (`1` = unigrams, `2` = bigrams, `3` = trigrams).

A single `<source>` may ship several n-gram sizes (e.g. `paperAbstract-ngram_1`,
`-ngram_2`, `-ngram_3`). A source with only one size renders with the N-gram
selector disabled.

## `*-counts.csv`

UTF-8 CSV with a header row. One row per `(date, topic)`.

| Column | Type | Description |
|--------|------|-------------|
| `date` | string `YYYY/M/D` | Year bucket; day/month are conventionally `1/1`. |
| `topic` | string | The theme (term or n-gram phrase). |
| `count` | integer | Number of papers on this theme in that year. |

The visualization derives each theme's stacked proportion (`adjusted_percent`)
from these counts at render time; it is not stored in the file.

Example:

```csv
date,topic,count
2013/1/1,Age Factors,18
2014/1/1,Age Factors,0
```

## `*-papers.json`

A nested object keyed by year, then by topic, whose value is an array of paper
records.

```jsonc
{
  "2013": {
    "epidemiological mathematical model": [
      {
        "title": "Increased transmissibility explains the third wave …",
        "uri": "https://midasnetwork.us/papers/…",
        "abstract": "…"
      }
    ]
  }
}
```

| Field | Type | Description |
|-------|------|-------------|
| `title` | string | Paper title. |
| `uri` | string (URL) | Link to the paper. |
| `abstract` | string | Paper abstract (shown on hover). |

Keys must match the `count`/`topic` values in the corresponding CSV: every
`(year, topic)` with a non-zero count should resolve to a papers array.

## `manifest.json`

Generated by `scripts/build-manifest.js` (run on `npm start`, in local deploy,
and in CI). The client fetches it to build its controls, so the data — not the
code — determines what is available. Do not edit it by hand.

```jsonc
{
  "schemaVersion": 1,
  "generatedAt": "2026-07-12T05:16:59.262Z",   // ISO-8601 build time (provenance)
  "title": "MIDAS ThemeRiver",
  "description": "…",
  "license": "MIT",
  "dataLicense": "CC-BY-4.0",
  "homepage": "https://midasnetwork.us",
  "minYear": 2013,
  "maxYear": 2025,
  "ngramLabels": { "1": "Unigrams", "2": "Bigrams", "3": "Trigrams" },
  "datasets": [
    {
      "id": "paperAbstract",
      "label": "Title + Abstracts",
      "ngrams": [1, 2, 3],
      "supportsNgrams": true,
      "default": true
    }
  ]
}
```

| Field | Description |
|-------|-------------|
| `schemaVersion` | Manifest schema version, for forward compatibility. |
| `generatedAt` | Build timestamp — data provenance. |
| `minYear` / `maxYear` | Year range across all datasets. |
| `datasets[].id` | Source id (the `<source>` in filenames). |
| `datasets[].ngrams` | Available n-gram sizes for this source. |
| `datasets[].supportsNgrams` | `false` when only one size exists (selector disabled). |
| `datasets[].default` | Which source is selected on load (exactly one is `true`). |
