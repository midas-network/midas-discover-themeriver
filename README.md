MIDAS River is a static browser-based visualization for exploring ThemeRiver data.

## HTML template and year stamping

- `index.template.html` is the source of truth for the page shell.
- `index.html` is generated by replacing `END_YEAR` with the latest year found in `data/*.csv`.
- In Cloud Build, this is handled automatically by the `stamp-themeriver-year` step before the Docker image build.

## Running locally

This project does not require a frontend build step, but it should be served through a local HTTP server because the frontend loads CSV and JSON files from the `data/` directory at runtime.

From the repository root:

1. Run the pipeline container to refresh data (for example, `docker compose run --rm pipeline`).
2. Stamp the end year into `index.html`:

```bash
bash scripts/stamp-themeriver-year.sh
```

3. Start services:

```bash
docker compose up
```

### Option 1: Python

From the project root, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

### Option 2: VS Code Live Server

If you use the Live Server extension in VS Code, open generated `index.html` with Live Server from the project root.

## Project structure

- `index.template.html` contains the app shell and UI layout template.
- `index.html` is generated from the template by the year-stamping script.
- `js/main.js` renders the visualization and loads data files.
- `data/` contains the CSV and JSON files used by the visualization.
- `css/` contains the app styles.
